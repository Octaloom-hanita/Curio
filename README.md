# Curio

Russian-first learning web app MVP.

## Current milestone

A web-first vertical slice for the Termite Mound Immersion.

Current prototype includes:
- Large accessible Russian typography
- Strong orange, green and purple design language
- Doodle-style illustration
- Learning flow
- Mock audio controls
- Text answer flow
- Feedback state
- Concept connection

Next:
- Real audio with ElevenLabs
- Real microphone recording in Chrome
- OpenAI transcription
- Rubric-based AI evaluation
- Supabase persistence

## Run

```bash
npm install
npm run web
```

## Build

```bash
npm run build
```

Vercel output directory: `dist`
