# Curio MVP QA Report

Date: 2026-09-20
Scope: current web-first private alpha on Vercel

## Overall status

The MVP is deployable and the basic learning flow is coherent, but it is not yet ready for an unassisted real-user test because the Gemini project currently returns a 403 access denial.

## What was tested

### Build and deployment
- Production deploy succeeds.
- TypeScript is now enforced before production build.
- Main web bundle returns HTTP 200.
- API route resolves separately from the SPA and rejects GET with 405.
- No current Vercel runtime error clusters were found outside the deliberate Gemini QA probe.

Status: PASS

### Learning flow
Checked against PRODUCT.md, 01_PRD.md, 03_LEARNING_MODEL.md, DESIGN.md and the termite vertical-slice documents.

Changes made during QA:
- Removed the pre-learning hypothesis question from the first-user flow.
- Added context before mechanism.
- Split the mechanism into understandable causal parts.
- Added a three-point summary before recall.
- Moved scientific nuance after the basic mental model.
- Added retry and return-to-explanation recovery paths.
- Kept a clear session ending.

Status: PASS for the current text-only slice

### Older-adult UX
Changes made:
- Large body text remains the default.
- Added an explicit larger-text control.
- Increased language-switch touch targets.
- Disabled unavailable topic cards instead of making them look actionable.
- Added explicit resume state.
- Learning position, answer draft, language and text-size preference persist locally.
- Resume is offered from the home screen rather than dropping the learner into a lesson without context.
- Reduced decorative illustrations and kept visuals only where they support a mechanism.
- Added captions to explanatory visuals.

Status: PASS for code-level UX rules
Still requires real-device observation.

### Localization
- Russian and English are externalized.
- Switching language preserves lesson position.
- HTML language is updated at runtime.
- Long Russian text is allowed to wrap.
- Topic and lesson titles were aligned.

Status: PASS

### Accessibility
Checked:
- Primary controls are at least 56 px high after QA fixes.
- Body text is large and scalable.
- Text/background contrast in the current palette is strong.
- Meaning does not rely on color alone in feedback.
- Decorative learning visuals are hidden from accessibility traversal.
- Text answer input has an accessibility label.

Status: PARTIAL
Still needs Chrome + screen-reader and keyboard-only testing on a real device/computer.

### Scientific content
The current termite explanation was checked against the project's cited literature, including:
- King, Ocko and Mahadevan, 2015
- Ocko et al., 2017
- Turner, 1994

QA changes:
- Kept species-specific caveats.
- Kept ventilation distinct from guaranteed temperature regulation.
- Clarified that termites build and modify structure through local actions, while airflow is not centrally controlled.
- Avoided presenting one termite ventilation mechanism as universal.

Status: PASS for this MVP explanation

### AI answer evaluation
Validated in code:
- Fixed rubric.
- AI extracts evidence rather than directly assigning mastery.
- App logic classifies the result.
- Input length is capped.
- Locale is normalized.
- Model output is validated before use.
- Learner answer is treated as untrusted prompt data.
- Misconceptions now produce explicit corrective feedback.
- Technical failures do not mark the learner wrong.
