# Curio - Product Vision and Scope

## Product thesis

Curio is a Russian-first, bilingual learning companion for curious adults.

It combines:
- broad discovery across books, topics, questions and phenomena
- original explanatory learning content
- text and audio as equal learning modes
- open-ended self-explanation
- rubric-based AI feedback
- active recall and delayed review
- concept connections across domains
- a contextual AI tutor grounded in approved material

The product is not a book-summary app, generic chatbot, audiobook player, school quiz app or infinite feed.

## Primary first user

The first real user is an older Russian-speaking adult learner with broad intellectual curiosity.

Important preferences:
- mechanisms and first principles
- evidence and scientific nuance
- progressive depth
- cross-domain connections
- reading and listening
- low-pressure learning
- large readable text
- no rigid curriculum
- no heavy gamification

The product must remain suitable for a broader adult audience later.

## Core loop

Discover -> Understand -> Explain -> Feedback -> Recall later -> Connect -> Explore deeper

Immediate understanding and durable memory are separate.

## Discovery model

Curio can be entered through:
- books
- topics
- questions
- phenomena
- Immersions

Books are important discovery objects.

Concepts are the reusable atomic knowledge units.

## Core domains for the initial knowledge library

1. Complex systems
2. Evolution and origins of life
3. Brain and neuroscience
4. Cognitive psychology and learning
5. Networks and social systems
6. Biomimicry and bio-inspired design

These domains are connected by recurring mechanisms such as:
- emergence
- feedback
- self-organization
- adaptation
- energy constraints
- prediction
- information flow
- network structure
- local rules producing global behavior

## Experience principles

1. Curiosity before completion.
2. Mechanism before slogan.
3. Evidence before confidence.
4. Explanation before testing when prior knowledge is unlikely.
5. Retrieval before passive rereading.
6. Feedback before scoring.
7. Context before generic AI chat.
8. Scientific nuance is part of the product.
9. Clear stopping points instead of infinite feeds.
10. The idea itself is the protagonist.

## Current MVP scope

The private alpha validates one complete learning loop on the web before broad platform expansion.

Current MVP includes:
- Russian and English UI
- topic selection
- accessible reading
- guided explanation
- open text answer
- real Gemini evaluation
- retry and review-explanation paths
- browser-local resume

Planned next:
- more content based on the source library
- ElevenLabs audio
- microphone recording
- transcription with editable confirmation
- Supabase persistence
- delayed review
- broader library/search

## Explicit non-goals for the current alpha

Do not prioritize:
- social features
- leaderboards
- streak pressure
- complex recommendation ML
- publisher integrations
- large CMS
- community
- gamification systems
- native App Store release before the core loop works well
